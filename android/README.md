# jfinances for Android

The household dashboard as a native app with home-screen widgets: the iPhone
app's twin. Read-only. See [docs/86-android.md](../docs/86-android.md) for what
is in it, how sign-in works, and how to build and install it:

```
Scripts/deploy-apk.sh          # serve on the tailnet; open the link in Chrome on the phone
Scripts/deploy-apk.sh --adb    # or install over USB
```
